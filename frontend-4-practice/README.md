# frontend-4-practice

Практическая работа №4: асинхронный JavaScript и React. Страница «Выбор даты и времени» получает сегодняшнюю дату и слоты через API имитационного сервера Vite.

## Запуск
1. Откройте папку проекта в терминале.
2. Выполните `npm install`.
3. Выполните `npm run dev`.
4. Откройте адрес, который Vite выведет в терминале (по умолчанию http://localhost:3000).

API для проверки:
- `http://localhost:3000/api/booking/today`
- `http://localhost:3000/api/slots?day=9&month=10&year=2026`

Месяц в параметре `month` указывается с нуля: 0 — январь, 10 — ноябрь.
