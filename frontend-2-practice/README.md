# frontend-2-practice

Практика 2: динамический календарь выбора даты и времени на нативном JavaScript.


## Запуск
Откройте `index.html` в браузере. Для работы скрипта не требуется установка библиотек или фреймворков.


## Реализовано
- динамическое построение календаря с 4–6 строками;
- переключение месяцев и годов;
- блокировка прошлых дат;
- выбор даты и времени;
- сброс времени при смене даты;
- обновление нижней панели.
