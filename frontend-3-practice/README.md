# frontend-3-practice

React-проект страницы записи в парикмахерскую «Стриж & Стиль».

## Запуск проекта

1. Откройте папку `frontend-3-practice` в Visual Studio Code.
2. Откройте терминал в этой папке.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите Vite:

   ```bash
   npm run dev
   ```

5. Откройте адрес, который Vite выведет в терминале (обычно `http://localhost:5173`).

## Реализовано

- Компонентная структура React.
- Состояние страницы через `useState`.
- Выбор даты в календаре и переключение месяцев.
- Выбор доступного времени.
- Сброс выбранного времени при смене даты.
- Отображение выбранной даты и времени в нижней панели.
- Прошедшие даты недоступны для выбора.

## Структура

- `src/App.jsx` — основная страница и состояние записи.
- `src/components/` — компоненты шапки, календаря, слотов, этапов, нижней панели и подвала.
- `src/styles.css` — стили страницы.
- `src/index.css` — базовые стили.
